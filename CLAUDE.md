# Portfolio Website (innarenard.com)

Статический сайт без сборки. GitHub Pages публикует ветку `main` на https://innarenard.com/
автоматически. Кейсы — папки вида `<case>/index.html`, все ссылки относительные.

## Главное правило работы

**Ничего не попадает в `main`, пока пользователь не скажет дословно:
«всё публикуем на главном сайте».**

Работаем в ветке `case/*`, после каждого изменения выдаём ссылку на локальный стенд
`http://localhost:8001/...`. Подробности и разбор отговорок — в скилле
`.claude/skills/staging-before-publishing/SKILL.md`, читать его перед любой правкой сайта.

## Второе правило: только LUNEL

**Пока пользователь не скажет дословно «теперь правим портфолио целиком», трогаем только
кейс Lunel:** папку `lunel/`, картинки `images/lunel-*` и блок Lunel в `index.html` / `js/i18n.js`.
Остальные кейсы и общие `css/`, `js/` — только читаем как эталон вёрстки, не правим.

## Третье правило: два языка синхронно

Тексты живут в `js/i18n.js` (словари `en` и `ru`) плюс английский запасной текст в HTML.
**Правка формулировки идёт сразу в обе локализации**, даже если ревью на русском.
Картинки с текстом нужны парами `_en` / `_ru`. Проверка:

```bash
python3 .claude/skills/staging-before-publishing/check-i18n-parity.py lunel_
```

## Четвёртое правило: проверять переключение глазами

Зелёный скрипт не значит, что переключатель работает: элемент без `data-i18n` он видит,
а вот применилось ли значение на странице — нет. **После каждой правки открываем стенд
и переключаем RU и EN в обе стороны.** Разбор ловушек — в правиле 4 скилла.

## Пятое правило: геометрию сначала замерить

Числа в `css/` не равны тому, что на экране: вертикальные отступы соседних секций
слипаются, медиа-запросы переопределяют, специфичность перебивает. **Правка размера
или отступа начинается с замера в браузере**, относительные просьбы («в два раза
меньше», «как у остальных») считаются от замера. Приёмы и уже замеренные факты —
в правиле 5 скилла.

## Шестое правило: имена приходят искажёнными

Правки диктуются голосом: «Cloud Code» — это Claude Code, «Mesh» — МЭШ,
«Кирилле» — этот файл. Берём ближайшее реально существующее в репозитории имя
и называем свою догадку в ответе. Вопросы — по-русски, максимально просто,
и только те, от которых меняется результат.

## Локальный стенд

```bash
python3 .claude/skills/staging-before-publishing/serve.py
```

Порт всегда 8001, чтобы ссылки были стабильными. Именно этот скрипт, а не голый
`python3 -m http.server`: он отдаёт `Cache-Control: no-store`, иначе браузер держит
старый `js/i18n.js` и новый блок остаётся английским при переключении на русский.
